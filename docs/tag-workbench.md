## 封面

- 默认铺满 16:9 封面区。自动封面、换图候选与保存校验统一要求该标签的模型置信度 **≥99%**，同一图片只能用作一个标签的封面（跨分页与重启保持）。手动补充／自定义标签不能充当模型置信度；没有合格且未占用的图片时显示占位。
- 用户可从合格候选中换图、拖动焦点、调节水平／垂直位置及 1–3 倍缩放，再固定封面。普通标签组合检索与图片预览保持原置信度范围。
- 自动选择按稳定图片键取得最多 96 个候选，结合现有打标置信度、尺寸、与封面比例的适配程度及收藏标记排序。
  在限制数量前排除不合格或其他标签已占用图片。最多核对 16 个靠前候选的可用路径；不运行新模型、不扫描全库原图。它是启发式候选，不能保证主体语义或最佳裁切。
- 手动固定优先，图片暂入回收站时临时使用自动封面，原图还原后仍可恢复固定选择。缺图、无可用候选时显示占位，不套用无关标签的图片。
- 手动设置保存到主库 `app_meta` 的 `tag-cover:v1:` 项，自动分配保存到 `tag-cover:auto:v2:` 项，仅记录引用、焦点及缩放，主库仍为 schema 3。旧版不合格／重复封面按稳定顺序重新分配；有效手动固定优先。只读或维护状态不产生新分配。
  不复制或改写原图，不新增整套封面图片缓存。完整 SQLite 备份自动包含设置，目录恢复映射同步更新公开图片引用；校验公开 ID 防止整数键复用造成错图。
- 卡片只按当前页请求封面，单批最多 24 个；默认每页 18 个。组合预览在 SQLite 直接分页，避免将常用标签的全部图片 ID 数组传至前端或构造成预览数组。
